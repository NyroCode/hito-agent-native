# Identificador histórico de Testnet

`contract-id.txt` conserva el identificador registrado en una sesión anterior. Su presencia no demuestra que el contrato siga disponible ni que se haya completado un pago.

La procedencia, la transacción `create` reportada y las verificaciones pendientes están en [REMAINING_GATES](../../docs/REMAINING_GATES.md). Los nuevos despliegues guardan informes separados; nunca sobrescriben este registro histórico.
